# hurricane-tracker-data
Public static feed for the hurricane tracker widget on cabosanlucas.net and puertovallarta.net.
A GitHub Actions workflow fetches the public US National Hurricane Center (NOAA) feed every 6 hours and publishes
hurricane-tracker.txt, hurricane-tracker.json, hurricane-tracker.min.js and hurricane-tracker.min.css to GitHub Pages.
Widget build: c5e5052. NOAA data is public domain.
